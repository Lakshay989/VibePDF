# Phase 4 — Content editing (decoupled steps)

> Goal (per `docs/05_ROADMAP.md`): edit existing text without breaking
> the document. Add new text, images, and decorations. **This is the
> hardest phase.** It's where the product earns the "elite" label.

## Acceptance demo (from roadmap)

- Open `tests/fixtures/acceptance/p4-edit-typo.pdf`. Edit the typo. Save. Diff against Acrobat's edit of the same document — text in same position, same font, no visual drift.
- Add a watermark to a 50-page PDF in under 2 seconds.
- Apply Bates numbers across three merged PDFs starting at `ABC000001` — confirm sequence is correct on every page.

## Spec coverage

`P4-EDIT-001` through `P4-EDIT-012` (12 spec lines). Plus 3 infrastructure steps for the text engine.

## Hard rule (from the roadmap)

Text editing is **intrinsically lossy** when fonts aren't embedded.
Be honest with the user; never silently substitute and pretend the
result is identical.

## Track A — Text engine infrastructure

### P4.A1. `[~]` Text run extraction + bounding boxes
- **Spec:** infrastructure for **P4-EDIT-001** (edit existing text) / P4-EDIT-004.
- **Touches (new):** `src-tauri/src/pdf/text_extract.rs`, `src/ipc/text-runs.ts`;
  (modify) `actor.rs` (`ReadTextRuns` read-only query), `commands/pdf.rs`
  (`pdf_extract_text_runs`), `lib.rs`, `mod.rs`.
- **What:** Walk each page's **PDFium text page-objects** (one ≈ one show
  operator = the natural edit unit) via the pdfium-render *high-level* API (no
  unsafe FFI) and emit a `TextRun { text, bbox[4] PDF-pts, fontName, embedded,
  fontSize, color #rrggbb, transform[6] }`. **Read-only**: runs on the *live*
  `PdfDocument` under the `PDFium` lock (like `render_page`), **not** the cos
  byte path — text decoding is PDFium's job. Subset tags (`ABCDEF+`) stripped;
  `embedded` surfaced to feed A2's font-fallback. The IPC is exposed for **P4.B1**
  to hit-test a click to a run; **no UI consumes it yet** (B1 wires it).
- **Test:** `src-tauri/tests/text_extract.rs` (extracts runs from `hello.pdf` with
  sane page-space bbox + populated font/size/colour; out-of-range page errors;
  stable across `links.pdf`/`forms.pdf`) + `text_extract.rs` unit (subset-tag
  strip, hex) + `src/ipc/__tests__/text-runs.test.ts`.
- **Acceptance:** infra step, no UI — the Rust test *is* the acceptance (it
  extracts the expected run(s) from `hello.pdf`). `check` + `test` (312) +
  `test:rust` green. No write path → no artifact.
- **`[~]`** because it's read-only infra with no user-facing surface yet; flips to
  `[x]` once B1 consumes it (or on an eyeball of logged runs, if wanted).
- **Depends on:** P2.A1, P2.A3.

### P4.A2. `[ ]` Font fallback resolver
- **Spec:** P4-EDIT-002
- **Touches (new):** `src-tauri/src/pdf/font_resolver.rs`, `src/app/FontFallbackBanner.tsx`
- **What:** When the original font isn't embedded and isn't on the system, choose the closest match from a fallback stack (Helvetica → Arial → sans-serif), warn the user **once per document**, and offer to re-flow the affected run.
- **Acceptance:** Open a PDF with a custom font referenced but not embedded → banner appears once, with "Re-flow" affordance.
- **Test:** `src-tauri/tests/font_fallback.rs`.
- **Depends on:** P4.A1.

### P4.A3. `[ ]` Two-phase redact-and-reflow primitive
- **Spec:** infrastructure for P4.B1/B2 (and P6.C1 redaction)
- **Touches (new):** `src-tauri/src/pdf/reflow.rs`
- **What:** Given a text run and new text, (1) remove the old run from the content stream, (2) emit a new text-showing operator with the same font/size/transform, (3) re-flow surrounding line breaks within the original bounding box.
- **Test:** `src-tauri/tests/reflow.rs`.
- **Depends on:** P4.A1, P4.A2.

## Track B — Text editing

### P4.B1. `[ ]` Edit existing text
- **Spec:** P4-EDIT-001
- **Touches:** `src/tools/text-edit/`, `src-tauri/src/pdf/text_edit.rs`
- **What:** Click a text run in edit mode → in-place editor at the run's bbox. Preserves font, size, color, style when possible.
- **Acceptance:** Edit "the" to "tha" in a contract → save → diff against Acrobat's edit — bbox within 1 px tolerance.
- **Test:** `src-tauri/tests/text_edit.rs`.
- **Depends on:** P4.A1, P4.A2, P4.A3.

### P4.B2. `[ ]` Add text box
- **Spec:** P4-EDIT-003
- **Touches:** `src/tools/text-add/`, `src-tauri/src/pdf/text_add.rs`
- **What:** Drag-create a text box. Full font / size / colour / style picker. Added to the page **content stream** (not as an annotation).
- **Test:** `src-tauri/tests/text_add.rs`.
- **Depends on:** P4.A2.

### P4.B3. `[ ]` Delete text run
- **Spec:** P4-EDIT-004
- **Touches:** `src-tauri/src/pdf/text_delete.rs`
- **What:** Remove a selected text run from the content stream. Re-flow surrounding content where possible.
- **Test:** `src-tauri/tests/text_delete.rs`.
- **Depends on:** P4.A1, P4.A3.
