# Phase 3 — Annotations (decoupled steps)

> Goal (per `docs/05_ROADMAP.md`): standard PDF annotations that
> round-trip through Acrobat, iOS Books, and Okular.

## Acceptance demo (from roadmap)

- Add five annotations of different types to `tests/fixtures/acceptance/p3-doc.pdf`. Save. Open in Acrobat Reader, iOS Books, and Okular. All five render correctly in all three.
- Open `tests/fixtures/acceptance/p3-annotated.pdf` (annotated in Acrobat) — every annotation shows in our sidebar with correct authors and timestamps.
- Export to XFDF → delete all annotations → re-import the XFDF → annotations restored identically.

## Spec coverage

`P3-ANN-001` through `P3-ANN-011` (11 spec lines). Plus 2 infrastructure steps.

---

## Track A — Annotation infrastructure

### P3.A1. `[ ]` Annotation tool framework
- **Spec:** infrastructure
- **Touches (new):** `src/tools/_framework/`, `src/state/annotation-store.ts`
- **What:** Common lifecycle for every annotation tool — `activate → pointerdown → pointermove → pointerup → commit/cancel`. Each concrete tool plugs in via the contract in `04_ARCHITECTURE.md §Edit tools`.
- **Test:** `src/tools/_framework/__tests__/lifecycle.test.ts`.
- **Depends on:** none (replaces the stubs from Phase 1).

### P3.A2. `[ ]` Annotation render layer
- **Spec:** infrastructure
- **Touches (new):** `src/view/annotation-layer.tsx`
- **What:** SVG layer mounted on top of each page canvas. Reads from `useAnnotationStore`, draws each annotation in its native PDF coordinate system. Hit-testing for select/edit.
- **Test:** `src/view/__tests__/annotation-layer.test.tsx`.
- **Depends on:** P3.A1, P1.C1 (virtual-scrolling page list).

---

## Track B — Text markup (read-only-content overlays)

### P3.B1. `[ ]` Highlight / underline / strikethrough / squiggly
- **Spec:** P3-ANN-001
- **Touches:** `src-tauri/src/pdf/annotation.rs`, `src/tools/text-markup/`
- **What:** Use PDF.js's text layer to capture user selection ranges, then write standard PDF text-markup annotations. Style colour configurable.
- **Acceptance:** Highlight a paragraph → save → open in Acrobat → highlight is visible and selectable.
- **Test:** `src-tauri/tests/text_markup.rs`.
- **Depends on:** P3.A1, P3.A2.

### P3.B2. `[ ]` Sticky notes (Text annotations)
- **Spec:** P3-ANN-002
- **Touches:** `src/tools/sticky-note/`, `src-tauri/src/pdf/annotation.rs`
- **What:** Click to place; opens a popup with author + timestamp + body. Editable + deletable from the sidebar.
- **Test:** `src-tauri/tests/sticky_note_roundtrip.rs`.
- **Depends on:** P3.A1, P3.A2.

### P3.B3. `[ ]` Free-text annotations (rich text)
- **Spec:** P3-ANN-003
- **Touches:** `src/tools/free-text/`, `src-tauri/src/pdf/annotation.rs`
- **What:** Box with font family / size / colour / bold / italic / underline. PDF rich-text annotation appearance stream generated server-side.
- **Test:** `src-tauri/tests/free_text.rs`.
- **Depends on:** P3.A1, P3.A2.

## Track C — Drawing

### P3.C1. `[ ]` Shapes — rectangle / ellipse / line / arrow / polygon
- **Spec:** P3-ANN-004
- **Touches:** `src/tools/shapes/`, `src-tauri/src/pdf/annotation.rs`
- **What:** Click-drag to draw. Stroke colour, fill colour, opacity, stroke width configurable. Arrow is line + end-style.
- **Test:** `src-tauri/tests/shapes.rs`.
- **Depends on:** P3.A1, P3.A2.

### P3.C2. `[ ]` Freehand ink with smoothing
- **Spec:** P3-ANN-005
- **Touches:** `src/tools/ink/`, `src-tauri/src/pdf/annotation.rs`
- **What:** Capture pointer path. Catmull-Rom smoothing in the frontend; persist as PDF Ink annotation. Pressure from `PointerEvent.pressure` where available; ignored otherwise.
- **Test:** `src/tools/ink/__tests__/smoothing.test.ts`.
- **Depends on:** P3.A1, P3.A2.

### P3.C3. `[ ]` Stamps — built-in library + custom
- **Spec:** P3-ANN-006
- **Touches:** `src/tools/stamp/`, `src/assets/stamps/`, `src-tauri/src/pdf/annotation.rs`
- **What:** Library: Approved, Confidential, Draft, Final, Reviewed, Void, Received, etc. Custom stamp builder from image, text, or combination.
- **Test:** `src-tauri/tests/stamp.rs`.
- **Depends on:** P3.A1, P3.A2.

### P3.C4. `[ ]` Measurement tools (distance / perimeter / area)
- **Spec:** P3-ANN-007
- **Touches:** `src/tools/measure/`, `src-tauri/src/pdf/annotation.rs`
- **What:** Calibrate against a user-specified scale (e.g. "this 50px = 1 m"). Display measured value as part of the annotation.
- **Test:** `src/tools/measure/__tests__/calibration.test.ts`.
- **Depends on:** P3.A1, P3.A2.

## Track D — Annotation management

### P3.D1. `[ ]` Annotation sidebar
- **Spec:** P3-ANN-008
- **Touches:** `src/panels/AnnotationPanel.tsx`
- **What:** List all annotations grouped by page. Filter by type, author, date. Clicking an entry scrolls to and selects the annotation.
- **Test:** `src/panels/__tests__/annotation-filter.test.ts`.
- **Depends on:** P3.A1.

### P3.D2. `[ ]` Reply threads
- **Spec:** P3-ANN-009
- **Touches:** `src/panels/AnnotationPanel.tsx`, `src-tauri/src/pdf/annotation.rs`
- **What:** Right-click an annotation → Reply. Persists as a linked annotation with `IRT` (in-reply-to) reference per the PDF spec.
- **Test:** `src-tauri/tests/reply_thread.rs`.
- **Depends on:** P3.D1.

---

## Track E — Interchange

### P3.E1. `[ ]` Import / export XFDF and FDF
- **Spec:** P3-ANN-010
- **Touches:** `src-tauri/src/pdf/xfdf.rs`, `src-tauri/src/pdf/fdf.rs`, `src/app/AnnotationExportDialog.tsx`
- **What:** Export all annotations to XFDF (preferred) or FDF. Import the inverse. Round-trip with Acrobat.
- **Test:** `src-tauri/tests/xfdf_roundtrip.rs`.
- **Depends on:** P3.A1.

### P3.E2. `[ ]` Flatten annotations
- **Spec:** P3-ANN-011
- **Touches:** `src-tauri/src/pdf/flatten.rs`
- **What:** Render every annotation into the page content streams permanently. The result is not undoable from the saved file (only via session history).
- **Test:** `src-tauri/tests/flatten_annotations.rs`.
- **Depends on:** P3.A1, P3.A2.
