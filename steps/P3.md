## Track A — Annotation infrastructure

### P3.A1. `[x]` Annotation tool framework
- **Status:** Landed (frontend-only infra, no PDF surface). `src/tools/_framework/`
  ships the **tool contract** (`AnnotationTool`: stateless pointer-gesture

### P3.A2. `[x]` Annotation render layer
- **Status:** Landed (frontend-only, no PDF surface — persistence is B1).
  `src/view/annotation-layer.tsx` is the per-page SVG overlay: draws committed

### P3.E1. `[~]` Import / export XFDF and FDF
- **Spec:** P3-ANN-010
- **Touches:** `src-tauri/src/pdf/xfdf.rs`, `src/ipc/interchange.ts`, `src/panels/AnnotationPanel.tsx`
- **What:** Export every annotation to an XFDF sidecar and import one back, restored
  with full fidelity (geometry, colour, opacity, `/NM` identity, reply threads).
  Export reads the raw dicts; import **reuses the canonical `cos::add_*` writers**
  (same `/AP`/`/BBox` as drawn annotations) then patches identity + wires `/IRT`
  in a second pass. Hand-rolled XFDF parser — no new dependency. **XFDF only this
  step; FDF (the spec's other half) deferred to E1b in BACKLOG** — so this lands
  `[~]` as honestly spec-partial. No format-picker dialog (no choice to make):
  two header actions drive the native save/open dialogs.
- **Test:** `src-tauri/tests/xfdf_roundtrip.rs` (4) + `xfdf.rs` parser units (8)
  + `src/ipc/__tests__/interchange.test.ts` + 2 `AnnotationPanel` tests.
- **Depends on:** P3.A1.
- **Verify (debt, logged in BACKLOG):** in-app round-trip (draw → Export → delete
  all → Import → restored, reply still threaded) **and** cross-reader (open the
  exported `.xfdf` against the same base PDF in Acrobat).
