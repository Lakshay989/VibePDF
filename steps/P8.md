# Phase 8 — AI & batch (decoupled steps)

> Goal (per `docs/05_ROADMAP.md`): optional, local-first AI features +
> batch processing. **Gated on the rest of the product being solid.**

## Acceptance demo (from roadmap)

- With Ollama running locally: ask "summarize this in 3 sentences" of `p8-paper.pdf` → coherent summary with page citations.
- Run "smart redact" on `p8-pii.pdf` → 12 PII entities identified → user confirms 10 / rejects 2 → only confirmed redacted.
- Watch folder: drop a PDF in → OCR'd + compressed + renamed per configured pipeline.

## Spec coverage

`P8-AI-001..007`, `P8-BATCH-001`, `P8-BATCH-002` (9 spec lines). Plus 2 infrastructure steps.

## Hard rule (from `docs/03_TECH_STACK.md`)

The AI subsystem must be **optional**. This phase adds **no required
dependencies** to earlier phases. AI features hide entirely if no
backend is configured. The settings UI shows the current backend at
all times.

---

## Track A — Local AI infrastructure

### P8.A1. `[ ]` Local LLM backend (Ollama detection + integration)
- **Spec:** P8-AI-001
- **What:** Probe `http://localhost:11434` on startup. If present, list installed models. If absent, offer a one-click install hint (link out — no bundled installer).
- **Touches:** `src-tauri/src/ai/ollama.rs`.
- **Test:** `src-tauri/tests/ollama_probe.rs` (with a mock server).
- **Depends on:** none.

### P8.A2. `[ ]` ONNX runtime + embedding model
- **Spec:** infrastructure for P8.B2 (Q&A) and P8.B4 (smart redact)
- **What:** Load `bge-small-en-v1.5` ONNX (~30 MB, bundled). Wrap `ort` crate behind a typed interface.
- **Touches:** `src-tauri/src/ai/embed.rs`.
- **Depends on:** none. **`ort` is in RC; lock the chosen RC version.**

---

## Track B — Generative features

### P8.B1. `[ ]` Summarize
- **Spec:** P8-AI-002
- **What:** Configurable length (3-sentence / 1-paragraph / bullet list). Streams from Ollama.
- **Depends on:** P8.A1.

### P8.B2. `[ ]` Q&A (RAG over open document)
- **Spec:** P8-AI-003
- **What:** Index pages via P8.A2 embeddings. On question, retrieve top-k passages, send to Ollama, answer with **page-number citations**.
- **Depends on:** P8.A1, P8.A2.

### P8.B3. `[ ]` Translate
- **Spec:** P8-AI-006
- **What:** Translate document text to a chosen target language. Output: new PDF, side-by-side or replacement.
- **Depends on:** P8.A1, P4.A1.

### P8.B4. `[ ]` Smart redact (PII NER)
- **Spec:** P8-AI-004
- **What:** Run a local NER model (multilingual distilBERT or similar, bundled). Surface candidates as a confirm-before-apply list (names, addresses, SSNs, credit cards, phones, emails, DOBs, account numbers).
- **Depends on:** P8.A2, P6.D1 (true redaction primitive).

### P8.B5. `[ ]` Extract structured data
- **Spec:** P8-AI-005
- **What:** Detect tables, forms, key-value pairs. Export as CSV / JSON / XLSX.
- **Depends on:** P8.A2.

### P8.B6. `[ ]` Cloud opt-in
- **Spec:** P8-AI-007
- **What:** When the user provides an API key and toggles "enable cloud," offer cloud models as an alternative backend **per-feature**. Current backend visible in the UI at all times. **No data leaves the machine unless this is explicitly enabled.**
- **Depends on:** P8.A1.

---

## Track C — Batch

### P8.C1. `[ ]` Batch operations panel
- **Spec:** P8-BATCH-001
- **What:** Apply any of {compress, OCR, watermark, redact, convert, password-protect, flatten} to a list of files. Progress visible + cancellable.
- **Depends on:** P7.A2, P7.C2, P4.D2, P6.D1, P6.C1, P5.C2.

### P8.C2. `[ ]` Watch folder + CLI mode
- **Spec:** P8-BATCH-002
- **What:** Watch a directory; apply a chosen pipeline to every PDF added. Pipeline runnable from the command line for scripting.
- **Depends on:** P8.C1.

P8.A1 → P8.B1 → P8.A2 → P8.B2 → P8.B3 → P8.B4 → P8.B5 → P8.B6 → P8.C1 → P8.C2
