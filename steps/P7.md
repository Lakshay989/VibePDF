# Phase 7 — OCR & conversion (decoupled steps)

> Goal (per `docs/05_ROADMAP.md`): scanned PDFs become searchable.
> PDFs convert to other formats and back.

## Acceptance demo (from roadmap)

- OCR a 30-page scanned manual → searchable PDF, visual layout unchanged.
- Convert a report.pdf to DOCX → headings are headings, tables are tables, images present.
- Compress 200MB of scans to <30MB with no visible quality loss at 100% zoom.

## Spec coverage

`P7-OCR-001` through `P7-OCR-011` (11 spec lines). Plus 1 infrastructure step.

## Tooling warning

`leptess` (the Rust crate this phase depends on) has had no release since 2023-02-21. Before P7.A1 lands, evaluate `tesseract-rs` or write a thin `bindgen` wrapper. See `docs/03_TECH_STACK.md` note on this.

## Track A — OCR

### P7.A1. `[ ]` Tesseract integration + preprocessing pipeline
- **Spec:** infrastructure for the rest of Track A
- **What:** Bundle English LSTM data (~15 MB). Image pipeline: deskew (imageproc), denoise (median filter), upscale to ≥300 DPI when input is lower.
- **Touches:** `src-tauri/src/ocr/tesseract.rs`, `src-tauri/src/ocr/preprocess.rs`.
- **Test:** `src-tauri/tests/ocr_smoke.rs` on a known scanned fixture.
- **Depends on:** none. **Tooling decision required first** (see warning above).

### P7.A2. `[ ]` OCR a scanned PDF → searchable PDF
- **Spec:** P7-OCR-001
- **What:** For each page image, run OCR → invisible text layer aligned to the visual text. Bundle data ships English; preserve visual layout.
- **Test:** `src-tauri/tests/ocr_to_searchable.rs`.
- **Depends on:** P7.A1.

### P7.A3. `[ ]` Language packs
- **Spec:** P7-OCR-002, P7-OCR-003
- **What:** Built-in: en, es, fr, de, zh-Hans, zh-Hant, ja, ko, ar, hi, pt, ru. On-demand language pack downloader (`tessdata_fast`), cached in `<app_data_dir>/tessdata/`. Preprocessing config toggle (P7-OCR-003 already covered by A1 — surface the toggles in UI).
- **Depends on:** P7.A1.

## Track B — Conversions out (PDF → ...)

### P7.B1. `[ ]` PDF → DOCX
- **Spec:** P7-OCR-004
- **What:** Preserve text, basic formatting (bold/italic/headings), images, table structures where detectable.
- **Test:** `src-tauri/tests/convert_docx.rs`.
- **Depends on:** P4.A1 (text run extraction).

### P7.B2. `[ ]` PDF → image (PNG / JPG / TIFF / WebP, 72-600 DPI)
- **Spec:** P7-OCR-005
- **Depends on:** P1.B3 (render-to-bitmap).

### P7.B3. `[ ]` PDF → plain text (UTF-8, reading order)
- **Spec:** P7-OCR-006
- **Depends on:** P4.A1.

### P7.B4. `[ ]` PDF → HTML (semantic, images extracted to sibling folder)
- **Spec:** P7-OCR-007
- **Depends on:** P4.A1.

### P7.B5. `[ ]` PDF → XLSX
- **Spec:** P7-OCR-008
- **What:** Extract detected tables to sheets. Warn if no tables found.
- **Depends on:** P7.B1.

---

## Track C — Other conversions

### P7.C1. `[ ]` Create PDF from files (DOCX / images / TXT / HTML)
- **Spec:** P7-OCR-009
- **What:** Preserve content, embed fonts, produce PDF/A-compatible output when requested.
- **Depends on:** none.

### P7.C2. `[ ]` Compress + Linearize
- **Spec:** P7-OCR-010, P7-OCR-011
- **What:** Three compression levels (low/medium/high) targeting image recompression, font subsetting, stream deflation. Show before/after size. Linearize = "optimize for web" (fast web view).
- **Depends on:** none.
